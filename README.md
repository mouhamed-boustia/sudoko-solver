# Sudoku Solver in C

## Description
This project is a Sudoku solver written in C.
It solves a 9x9 Sudoku puzzle by filling empty cells with valid numbers.

## Input
The user enters a 9x9 Sudoku grid.
Empty cells are represented by 0.

## Output
The program displays the original Sudoku grid and the solved grid.

## How to Run
1. Compile the program:
   gcc sudoku.c -o sudoku
2. Run the program:
   ./sudoku
3. Enter the Sudoku grid when prompted
